# Student Performance Analytics

## Project Description
Student Performance Analytics is a Python-based project that analyzes student marks, attendance, grades, and department-wise performance.

## Technologies Used
- Python
- Pandas
- NumPy

## Features
- Calculates total and average marks.
- Assigns grades to students.
- Identifies pass and fail students.
- Finds the highest and lowest averages.
- Calculates subject-wise and department-wise averages.
- Identifies the top-performing students.
- Exports the student report to a CSV file.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy`
3. Run:
   `python main.py`

## Project Files
- `main.py` – Main Python program.
- `student_performance_analytics.csv` – Student dataset.
